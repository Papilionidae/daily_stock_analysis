# 12-1 动量 (12-Month Minus 1-Month Momentum)

## 基本信息

| 字段 | 值 |
|------|-----|
| 策略 ID | `momentum_12_1` |
| 名称 | 12-1 动量 |
| 分类 | 趋势 (trend) |
| 优先级 | 18 |
| 默认激活 | ❌ |
| 关联理念 | 第 2 条（趋势交易）、第 3 条（筹码效率）、第 6 条（估值关注） |
| 市场状态 | `trending_up` |
| 别名 | 动量、12月动量、跨周期动量、momentum |

## 核心逻辑

基于 Academic Momentum（Asness 1995）的策略：过去 11 个月动量（剔除最近 1 个月）。跨周期动量验证，避免短期反转假信号。

**⚠️ A 股注意事项**：2018 年后动量因子 alpha 显著衰减，需结合质量因子过滤，每 6 月做 IC 复检。

### 判断链

1. **动量计算**
   - MOM_11 = (当前收盘价 / 11 个月前收盘价) - 1（约 250 个交易日）
   - MOM_1 = (当前收盘价 / 1 个月前收盘价) - 1（约 20 个交易日）
   - MOM_12_1 = MOM_11（天然剔除最近 1 个月）
   - 调用 `get_daily_history` 拉 250 个交易日数据手动计算

2. **入场条件（同时满足）**
   - MOM_12_1 > 0（过去 11 个月累计正收益）
   - 当前价格 > MA20（不在深度回调中）
   - MOM_1 在 -10% ~ +20% 区间（允许正常回调）
   - 排除 MOM_11 < 0（长期下跌趋势不适用）
   - 排除 MOM_1 < -15%（短期暴跌可能是趋势反转）

3. **动量强度评级**

| MOM_11 范围 | 评级 | 调整 |
|-------------|------|------|
| > 30% | 强动量 | `sentiment_score +15` |
| 10% ~ 30% | 中动量 | `sentiment_score +10` |
| 0% ~ 10% | 弱动量 | `sentiment_score +5` |

4. **入场偏好**
   - **首选**：强动量 + 中短期回调（MOM_1 在 -5% ~ 0%）→ 顺势上车
   - **次选**：中动量 + 缩量企稳在 MA10 附近 → 等待突破
   - **严拒**：强动量但 MOM_1 > 30% → 短期过热，均值回归风险

5. **止损与持仓**
   - 止损：MA20 下方 3%，或 MOM_1 < -20% 主动减仓
   - 持仓周期：3-6 个月（中长期持有）
   - 再平衡：每月检查 MOM_12_1 是否仍 > 0，跌破则减半仓

6. **风险提示**
   - 2018 年后 A 股动量因子 alpha 显著衰减，需 ROE > 10% 过滤
   - 风格切换期（2014 末、2019 初、2021 初）动量可能短期失效
   - 熊市环境下动量策略可能 6-12 个月跑输反转策略
   - 必须每 6 月做 IC 复检

## 技术指标与数据依赖

| 数据/工具 | 用途 |
|-----------|------|
| `get_daily_history` | 拉取 250 个交易日数据，计算 MOM |
| `analyze_trend` | MA20 位置确认 |
| `get_realtime_quote` | 当前价格 |
| MA20 | 回调深度检查 |
| MOM_11 / MOM_1 | 动量计算 |

## 适用场景

- **适合**：中长期上升趋势延续、跨周期持仓决策
- **不适合**：短线交易、震荡市（动量频繁反转）、熊市环境
- **市场阶段**：牛市或结构牛中效果最佳

## 与上下游策略的关系

| 策略 | 关系 |
|------|------|
| `bull_trend` | 互补：bull_trend 偏短中期 MA 排列（5/10/20 日），本策略偏 11 月长期动量 |
| `short_term_reversal` | 互补：动量找"涨的还在涨"，反转找"跌的要反弹" |
| `multi_factor` | 配合：本策略的动量因子可作为 multi_factor 的输入之一 |

## 在管道中的角色

- **specialist 模式**：当市场状态为 `trending_up` 时可选
- **长期视角**：与其他趋势策略配合，提供中长期动量验证
- **IC 复检**：需定期检查因子有效性，失效时自动降权

# 一阳夹三阴 (One Yang Three Yin)

## 基本信息

| 字段 | 值 |
|------|-----|
| 策略 ID | `one_yang_three_yin` |
| 名称 | 一阳夹三阴 |
| 分类 | 形态 (pattern) |
| 优先级 | 110 |
| 默认激活 | ❌ |
| 关联理念 | 第 2 条（趋势交易）、第 4 条（买点偏好） |
| 市场状态 | 无特定绑定 |
| 别名 | 一阳穿三阴、一阳夹三阴 |

## 核心逻辑

检测 K 线整理形态——大阳线后跟三根缩量小阴线再跟一根阳线突破——趋势延续入场信号。

### 形态定义（最近 5 个交易日）

```
第1日: ┃ 大阳线 (实体 > 股价的 2%)
第2日: ┃ 阴线/小K线 (最低不破第1日开盘价)
第3日: ┃ 阴线/小K线 (最低不破第1日开盘价)
第4日: ┃ 阴线/小K线 (最低不破第1日开盘价)
第5日: ┃ 阳线 (收盘价突破第1日收盘价)
```

### 判断链

1. **形态定义（最近 5 个交易日）**
   - **第 1 日**：大阳线（收盘 > 开盘，实体 > 股价的 2%）
   - **第 2-4 日**：连续三根阴线或小 K 线
     - 每根 K 线最低价不跌破第 1 日开盘价
     - 成交量应逐步萎缩（量比 < 0.8）
     - 三根 K 线应收在第 1 日实体范围内
   - **第 5 日**：又一根阳线，收盘价突破第 1 日收盘价

2. **如何使用工具评估**
   - 调用 `get_daily_history` 获取最近 10 日数据
   - 检查最后 5 根 K 线是否符合上述形态
   - 调用 `analyze_trend` 确认多头排列（MA5 > MA10 > MA20）

### 评分调整

| 条件 | 调整 |
|------|------|
| 形态成立 + 趋势看多 | `sentiment_score +15` |
| 形态成立但趋势不明 | `sentiment_score +5` |
| 理想买点设在第 5 日收盘价附近 | 止损设在第 1 日开盘价下方 |

## 技术指标与数据依赖

| 数据/工具 | 用途 |
|-----------|------|
| `get_daily_history` | 最近 10 日 K 线数据 |
| `analyze_trend` | 多头排列确认 |
| K 线实体 | 大阳线判定（> 2%） |
| 成交量 | 缩量确认（量比 < 0.8） |

## 适用场景

- **适合**：上升趋势中的横盘整理结束、突破前蓄势已完成
- **不适合**：下跌趋势中的形态（可能是下跌中继）、成交量未萎缩的形态
- **市场阶段**：上升趋势中的整理阶段

## 与上下游策略的关系

| 策略 | 关系 |
|------|------|
| `bull_trend` | 上层：本形态需要多头排列作为前提条件 |
| `shrink_pullback` | 相似：都是整理后的入场信号，但形态定义不同 |
| `volume_breakout` | 配合：第 5 日阳线往往伴随放量突破 |

## 在管道中的角色

- **specialist 模式**：在所有市场状态下都可用（无绑定市场状态）
- **形态信号**：属于 K 线形态策略，与趋势策略配合使用
- **Score 权重**：形态 + 趋势的叠加评分较高（+15）

```yaml
# K-line pattern: bullish → 3 small bearish → bullish. Consolidation end signal.

name: one_yang_three_yin

core_rules: [2, 4]

  - get_daily_history
  - analyze_trend
aliases: [一阳穿三阴, 一阳夹三阴]
default_priority: 110

instructions: |
  **一阳夹三阴（One Yang Three Yin Strategy）**

  形态定义（最近 5 个交易日）：

  1. **第1日**：大阳线（收盘价 > 开盘价，实体 > 股价的 2%）。
  2. **第2-4日**：连续三根阴线或小K线：
     - 每根K线最低价不跌破第1日开盘价。
     - 成交量应逐步萎缩（量比 < 0.8）。
     - 三根K线应收在第1日实体范围内。
  3. **第5日**：又一根阳线，收盘价突破第1日收盘价。

  如何使用工具评估：

  1. 使用 `get_daily_history` 获取最近 10 日数据。
  2. 检查最后 5 根K线是否符合上述形态。
  3. 使用 `analyze_trend` 确认多头排列（关联理念2：趋势交易，MA5 > MA10 > MA20）。

  评分调整：
  - 形态成立 + 趋势看多：sentiment_score +15
  - 形态成立但趋势不明：sentiment_score +5
  - 在 `pattern_analysis` 和 `buy_reason` 中注明"一阳夹三阴"。
  - 理想买点设在第5日收盘价附近，止损设在第1日开盘价下方。
```

# 成长质量 (Growth Quality)

## 基本信息

| 字段 | 值 |
|------|-----|
| 策略 ID | `growth_quality` |
| 名称 | 成长质量 |
| 分类 | 框架 (framework) |
| 优先级 | 55 |
| 默认激活 | ❌ |
| 关联理念 | 第 2 条（趋势交易）、第 3 条（筹码效率）、第 5 条（风险排查） |
| 市场状态 | `trending_up` |
| 别名 | 成长、成长股、成长质量 |

## 核心逻辑

结合收入利润增长、ROE、现金流和行业空间，识别高质量成长股与成长失速风险。

### 与 `multi_factor` 的区别

| 维度 | 成长质量 (growth_quality) | 多因子选股 (multi_factor) |
|------|--------------------------|--------------------------|
| 视角 | 单股绝对质量评分 | 横截面相对分位数 |
| 重点 | 基本面深度分析 | 因子量化打分 |
| 适用 | 你有一个股票，想了解其成长质量 | 你有一个股票池，想排序筛选 |

### 判断链

1. **成长性**
   - 查看财报字段中的营业收入、归母净利润、经营现金流和 ROE
   - 判断收入增长和利润增长是否同向，是否存在"增收不增利"
   - 若只有概念热度但财报尚未验证，应降低成长确定性

2. **质量**
   - ROE 越高且稳定，质量越好
   - 经营现金流与净利润方向一致，说明盈利质量更可靠
   - 现金流显著弱于利润时，提示回款、存货或应收风险

3. **估值承受力**
   - 使用 PE/PB、市值等判断市场是否已提前透支成长
   - 高成长可承受更高估值，但必须说明增长能否覆盖估值
   - 估值高且成长放缓时，应明显下调评分

4. **趋势确认**
   - 调用 `analyze_trend` 判断长期成长逻辑是否被市场资金确认
   - 基本面向好但技术面未确认时，优先给"观察条件"而非直接追买

### 成长阶段判定

需明确公司所处的成长阶段：

| 阶段 | 特征 | 策略 |
|------|------|------|
| 高质量成长 | 收入/利润/ROE/现金流同向改善 | 积极介入 |
| 成长验证中 | 向好但财报尚未完全确认 | 观察等待 |
| 成长放缓 | 增速下降但仍在增长 | 降低权重 |
| 成长证伪 | 核心增长逻辑被打破 | 回避/减仓 |

### 评分调整

| 条件 | 调整 |
|------|------|
| 收入、利润、现金流和 ROE 同向改善 | `sentiment_score +15` |
| 行业景气与公司新闻互相验证 | 额外 +6 |
| 高估值但成长未验证 | `sentiment_score -8` |
| 增收不增利或现金流恶化 | `sentiment_score -12` |

## 技术指标与数据依赖

| 数据/工具 | 用途 |
|-----------|------|
| `get_stock_info` | 财报数据（营收、利润、ROE、PE、PB） |
| `get_realtime_quote` | 实时价格、市值 |
| `search_stock_news` | 行业景气度、公司新闻 |
| `analyze_trend` | 趋势评分、均线位置确认 |
| ROE | 质量核心指标 |
| PE/PB | 估值承受力判断 |
| 经营现金流 | 盈利质量验证 |

## 适用场景

- **适合**：高景气行业、业绩持续改善、商业模式扩张阶段的公司
- **不适合**：纯题材炒作、无基本面支撑的短期波动
- **市场阶段**：业绩驱动或成长风格占优的市场

## 与上下游策略的关系

| 策略 | 关系 |
|------|------|
| `multi_factor` | 互补：本策略做单股绝对质量评价，`multi_factor` 看同行业相对位置 |
| `expectation_repricing` | 延伸：成长质量变化往往引发预期重估 |
| `event_driven` | 验证：财报发布是验证/证伪成长判断的关键事件 |
| `bull_trend` | 配合：基本面确认后需趋势确认才介入 |

## 在管道中的角色

- **specialist 模式**：当市场状态为 `trending_up` 时可选
- **基本面深度**：提供最全面的基本面分析视角
- **Score 权重**：最高可 +15，但对数据的时效性要求高

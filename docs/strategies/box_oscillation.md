# 箱体震荡 (Box Oscillation)

## 基本信息

| 字段 | 值 |
|------|-----|
| 策略 ID | `box_oscillation` |
| 名称 | 箱体震荡 |
| 分类 | 框架 (framework) |
| 优先级 | 50 |
| 默认激活 | ❌ |
| 关联理念 | 第 1 条（严进不追高）、第 2 条（趋势交易）、第 3 条（筹码效率） |
| 市场状态 | `sideways` |
| 别名 | 箱体、箱体震荡 |

## 核心逻辑

识别价格箱体区间，在箱底买入、箱顶减仓，适用于横盘震荡行情。

**核心逻辑**：箱体内部价格在阻力位与支撑位之间反复震荡，"贴着支撑买、接近阻力卖"，通过波段操作获取区间收益。

### 判断链

#### 1. 箱体识别
- 调用 `get_daily_history` 获取近 60~120 日数据
- **箱体顶部（阻力位）**：近期多次触碰但未有效突破的高点连线（20~60 日内 3 次以上）
- **箱体底部（支撑位）**：近期多次下探但未有效跌破的低点连线
- 箱体有效性：顶部和底部各至少触碰 2~3 次方可确认
- 使用 `analyze_trend` 的 support_levels / resistance_levels 辅助定位

#### 2. 当前位置判断

| 位置 | 距箱体边界 | 策略 |
|------|-----------|------|
| 箱底区域 | 距支撑 ≤ 5% | 买入/加仓，止损设箱底下方 3% |
| 箱中区域 | 箱体中间 1/3 | 观望，不主动操作 |
| 箱顶区域 | 距阻力 ≤ 5% | 减仓/止盈，不追高 |

#### 3. 量能辅助判断
- **箱底放量企稳**：支撑有效的强信号，可较重仓
- **箱顶缩量滞涨**：阻力有效的卖出信号
- **箱体突破（放量 > 2 倍均量）**：
  - 向上有效突破 → 转为多头趋势策略，新目标 = 箱体高度延伸
  - 向下有效跌破 → 离场等待，原支撑转阻力

#### 4. 箱体宽度与预期收益

| 箱体宽度 | 操作空间 | 策略 |
|----------|----------|------|
| < 5% | 过小 | 不建议参与 |
| 5% ~ 15% | 标准 | 波段操作可行 |
| > 15% | 大箱体 | 可做更大波段 |

#### 5. 假突破识别
- 单日盘中触及阻力/支撑后快速回撤，收盘回到箱内 → 假突破，维持箱体操作
- 连续两日收盘突破箱体边界，且量能放大 → 真突破，修改策略

### 评分调整

| 条件 | 调整 |
|------|------|
| 箱底企稳 + 缩量 | `sentiment_score +10` |
| 箱底放量攻顶 | `sentiment_score +12` |
| 箱体向上有效突破 | `sentiment_score +15`（转趋势策略） |
| 处于箱顶区域 | `sentiment_score -5`（不追高） |
| 箱底有效跌破 | `sentiment_score -15`（离场） |

## 技术指标与数据依赖

| 数据/工具 | 用途 |
|-----------|------|
| `get_daily_history` | 60-120 日高低点、成交量 |
| `analyze_trend` | 支撑阻力辅助定位 |
| `get_realtime_quote` | 当前价格位置 |
| 成交量 | 箱底放量/箱顶缩量/突破确认 |

## 适用场景

- **适合**：横盘震荡行情、明确箱体的波段操作
- **不适合**：单边趋势行情（应在突破后切换策略）、箱体宽度过小的品种
- **市场阶段**：震荡市中表现最佳；趋势市中应等待突破确认后再操作

## 与上下游策略的关系

| 策略 | 关系 |
|------|------|
| `bull_trend` | 转换：箱体向上突破后应切换至趋势策略 |
| `volume_breakout` | 配合：箱体突破是放量突破策略的输入 |
| `short_term_reversal` | 补充：箱底区域的超跌反弹机会 |
| `bottom_volume` | 配合：箱底放量确认支撑有效 |

## 在管道中的角色

- **specialist 模式**：当市场状态为 `sideways` 时优先选入
- **震荡市框架**：提供与趋势策略不同的操作逻辑——箱体内买卖而非持有
- **突破监控**：持续跟踪箱体边界是否被有效突破，突破后修改策略

  "贴着支撑买、接近阻力卖"，通过波段操作获取区间收益。

  ## 分析步骤

  ### 1. 箱体识别
  使用 `get_daily_history` 获取近 60~120 日数据：

  - **箱体顶部（阻力位）**：近期多次触碰但未有效突破的高点连线。

  - **箱底区域**（距支撑 ≤5%）：买入/加仓信号，止损设箱底下方 3%。
  - **箱中区域**（箱体中间 1/3）：观望，不主动操作。
  - **箱顶区域**（距阻力 ≤5%）：减仓/止盈信号，无需追高。

  - **箱底放量企稳**：支撑有效的强信号，可较重仓。

    - 向上有效突破 → 转为多头趋势策略，新目标 = 箱体高度延伸。
    - 向下有效跌破 → 离场等待，原支撑转阻力。

  ### 4. 箱体宽度与预期收益
  - 计算箱体宽度：(顶部 - 底部) / 底部 × 100%。
  - 宽度 < 5%：操作空间过小，不建议参与。
  - 宽度 5%~15%：标准箱体，波段操作可行。
  - 宽度 > 15%：大箱体，可做更大波段。

  - 连续两日收盘突破箱体边界，且量能放大 → 真突破，修改策略。

  ### 6. 输出要求
  - 明确给出箱体顶部价位和底部价位。
  - 当前价格所处区间（箱底/箱中/箱顶）。
  - 若价格已突破，说明突破方向及新目标。
  - 建议仓位与止损位。

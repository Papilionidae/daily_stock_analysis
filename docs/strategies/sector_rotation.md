# 行业轮动 (Sector Rotation)

## 基本信息

| 字段 | 值 |
|------|-----|
| 策略 ID | `sector_rotation` |
| 名称 | 行业轮动 |
| 分类 | 框架 (framework) |
| 优先级 | 12 |
| 默认激活 | ❌ |
| 关联理念 | 第 2 条（趋势交易）、第 3 条（筹码效率）、第 6 条（估值关注） |
| 市场状态 | `trending_up`, `sector_hot` |
| 别名 | 行业轮动、主线行业、板块轮动、sector |

## 核心逻辑

用板块动量 + 资金流 + 涨停共振打分排序，识别主线行业，在个股分析中判断所属板块的相对强弱。

### 与 `dragon_head` 的区别

| 维度 | 行业轮动 (sector_rotation) | 龙头策略 (dragon_head) |
|------|---------------------------|----------------------|
| 关注层级 | 板块级排名 | 个股级龙头识别 |
| 输入 | 板块指数数据 | 个股数据 |
| 输出 | 主线/中性/弱势板块 | 龙头/跟风/无关 |

### 判断链

1. **板块打分（四维合成）**

| 维度 | 内容 | 数据源 |
|------|------|--------|
| 动量 | 板块 5/20/60 日累计收益 | `get_sector_rankings` |
| 资金流 | 北向资金 + 主力资金净流入 | 数据源（如有） |
| 涨停共振 | 板块成分股近 3 日涨停数量 | `get_sector_rankings` |
| 主题热度 | 板块名称的近期新闻密度 | `search_stock_news` |

每个维度 0-100 分，等权合成板块综合得分。

2. **主线条识别**
   - 综合得分 top 3 板块 = 主线
   - 持续 3 个交易日以上才算稳定主线（避免一日游）
   - 主线特征：得分差 > 5 分（与第 4 名拉开距离）

3. **个股映射与评分**
   - 处于主线条 top 5 板块 → `sentiment_score +10`
   - 处于弱势板块（bottom 5） → `sentiment_score -10`
   - 中性板块 → `sentiment_score ±0`，但需说明"板块不共振"

4. **入场偏好**
   - 优先在主线板块的龙头股或回踩不破的个股中找机会
   - 严格回避弱势板块的"补涨"诱惑（胜率不足 35%）
   - 主线板块切换时需在 `buy_reason` 明确说明

### 评分调整

| 条件 | 调整 |
|------|------|
| 个股在主线 top 5 板块 | `sentiment_score +10` |
| 个股在弱势 bottom 5 板块 | `sentiment_score -10` |
| 主线切换（60 日排名变化 > 5 位） | 需在 `buy_reason` 说明 |

## 技术指标与数据依赖

| 数据/工具 | 用途 |
|-----------|------|
| `get_sector_rankings` | 板块动量、涨停数量 |
| `get_daily_history` | 个股所属板块确认 |
| `get_realtime_quote` | 实时价格 |
| `search_stock_news` | 板块新闻热度 |

## 适用场景

- **适合**：板块轮动明显的结构性行情、主线明确的趋势市
- **不适合**：普涨普跌的无差异行情、板块效应不明显的个股独立行情
- **市场阶段**：A 股典型的板块轮动行情中效果突出

## 与上下游策略的关系

| 策略 | 关系 |
|------|------|
| `dragon_head` | 配合：本策略选板块，`dragon_head` 锁定板块内龙头 |
| `hot_theme` | 增强：板块动量 + 题材热度互相验证 |
| `bull_trend` | 过滤：只在主线板块中应用多头趋势策略 |

## 在管道中的角色

- **specialist 模式**：当市场状态为 `trending_up` 或 `sector_hot` 时自动选入
- **前置过滤**：在个股分析前先判断板块强弱，避免在不共振的板块中无效交易
- **Score 权重**：板块维度 ±10 分，对总评分影响较大

## YAML 配置原文

```yaml
# 行业轮动策略 / Sector Rotation
name: sector_rotation
display_name: 行业轮动
description: 用板块动量 + 资金流 + 涨停共振打分排序，识别主线行业，
  在个股分析中判断所属板块的相对强弱。
category: framework
core_rules: [2, 3, 6]
required_tools:
  - get_sector_rankings
  - get_daily_history
  - get_realtime_quote
  - search_stock_news
default_priority: 12
market_regimes: [trending_up, sector_hot]
aliases: [行业轮动, 主线行业, 板块轮动, sector]

instructions: |
  **行业轮动策略（Sector Rotation）**

  适用场景：
  - 个股分析时优先判断其所属板块的相对强度。
  - 在主线板块中寻找龙头/回踩机会，避开弱势板块的"补涨"陷阱。
  - 与 dragon_head 的差异：本策略关注板块级排名，dragon_head 关注个股级龙头识别。

  分析框架：

  1. **板块打分（四维合成）**
     - 维度 1 - 动量：板块 5/20/60 日累计收益，使用 `get_sector_rankings` 获取。
     - 维度 2 - 资金流：北向资金 + 主力资金净流入方向（如有数据源）。
     - 维度 3 - 涨停共振：板块成分股中近 3 日涨停数量。
     - 维度 4 - 主题热度：使用 `search_stock_news` 检索板块名称的近期新闻密度。
     - 每个维度 0-100 分，等权合成板块综合得分。

  2. **主线条识别**
     - 综合得分 top 3 板块 = 主线。
     - 持续 3 个交易日以上的才算稳定主线（避免一日游）。
     - 主线板块的特征：得分差 > 5 分（与第 4 名拉开距离）。

  3. **个股映射与评分**
     - 个股分析时，必须先调用 `get_sector_rankings` 确认其所属板块的位置。
     - 处于主线条 top 5 板块 → `sentiment_score +10`。
     - 处于弱势板块（bottom 5） → `sentiment_score -10`。
     - 中性板块 → `sentiment_score ±0`，但需在报告中明确说明"板块不共振"。

  4. **入场偏好**
     - 优先在主线板块的龙头股或回踩不破的个股中找机会。
     - 严格回避弱势板块的"补涨"诱惑（统计上胜率不足 35%）。
     - 当主线板块切换时（如 60 日排名变化 > 5 位），需在 `buy_reason` 明确说明。

  5. **风险提示**
     - 板块热度由情绪主导时（短消息刺激），需叠加 `core_rule 5`（新闻风险排查）。
     - 当主线板块与大盘趋势背离时（如大盘下行但板块领涨），降级为"防守型机会"。

  6. **输出规范**
     - 在 `buy_reason` 中必须包含 "板块：{板块名}（主线/中性/弱势）"。
     - 在 `risk_warning` 中标注板块拥挤度（如成分股连续涨停数 > 5 时）。
```

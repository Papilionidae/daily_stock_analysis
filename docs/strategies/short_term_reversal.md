# 短期反转 (Short-term Reversal)

## 基本信息

| 字段 | 值 |
|------|-----|
| 策略 ID | `short_term_reversal` |
| 名称 | 短期反转 |
| 分类 | 反转 (reversal) |
| 优先级 | 14 |
| 默认激活 | ❌ |
| 关联理念 | 第 2 条（趋势交易）、第 4 条（买点偏好）、第 6 条（估值关注） |
| 市场状态 | `trending_down`, `sideways` |
| 别名 | 短期反转、超跌反弹、反转、reversal |

## 核心逻辑

利用 A 股 5-10 日短期反转效应，在个股超跌后配合趋势/量能过滤找反弹机会。

**出处**：Jegadeesh 1990；A 股 王永宏&赵学军 2001、鲁臻&邹恒甫 2007 — 中国实证显著（夏普 1.5+，2005-2022 全周期）。

### 与 `bottom_volume` 的区别

| 维度 | 短期反转 | 底部放量 |
|------|----------|----------|
| 核心信号 | 5-10 日跌幅 + 趋势过滤 | 量能见底 + 放量反转 |
| 量能角色 | 辅助（企稳信号需要量） | 主导（放量 3 倍是关键信号） |
| 适用阶段 | 超跌后的企稳初期 | 长期下跌后的底部确认 |

### 判断链

1. **超跌判定（基础条件，全部满足才进入下一步）**
   - 过去 5 日累计跌幅 > 8%
   - 过去 10 日累计跌幅 > 12%
   - 当前价格距离 20 日均线 > 5% 偏离
   - 排除 ST、退市风险股、停牌股

2. **企稳信号（至少满足 2 条）**
   - 当日 K 线收阳（收盘 > 开盘）
   - 当日成交量较 5 日均量放大 1.2 倍以上
   - 出现长下影线（下影线 / K 线实体 > 1.5）
   - 当日未创新低（相对前 10 日最低点有 > 2% 缓冲）

3. **趋势过滤（必须执行）**
   - 调用 `analyze_trend` 检查 MA20 斜率
   - MA20 斜率走平或向上 → 反弹概率高（`sentiment_score +12`）
   - MA20 斜率仍向下 → 反弹概率低（`sentiment_score -5`），需写"二次探底风险"
   - 不能在 MA5 > MA10 > MA20 多头排列时使用（此时应走 `bull_trend`）

4. **入场偏好**
   - **首选**：超跌 + 放量长下影 + MA20 走平
   - **次选**：超跌 + 连续两日缩量企稳（地量见底）
   - **严拒**：超跌 + 跌破前低 + 缩量阴跌

5. **止损规则**
   - 硬止损：买入价下方 5%，或前 10 日最低点下方 1%
   - 时间止损：3 个交易日内未出现反弹 > 3%，需主动减仓
   - 反弹目标：5 日均线（保守）/ MA20（乐观）

### 评分调整

| 条件 | 调整 |
|------|------|
| MA20 斜率走平或向上 | `sentiment_score +12` |
| MA20 斜率仍向下 | `sentiment_score -5` |

## 技术指标与数据依赖

| 数据/工具 | 用途 |
|-----------|------|
| `get_daily_history` | 5/10 日跌幅计算、成交量验证 |
| `analyze_trend` | MA20 斜率、趋势评分 |
| `get_realtime_quote` | 当前价格、盘中走势 |
| MA20 | 趋势过滤、价格偏离 |
| 成交量 | 企稳信号中的量能确认 |
| K 线形态 | 长下影线检测 |

## 适用场景

- **适合**：短期超跌后的反弹交易、震荡市中的波段低点
- **不适合**：多头排列的强势股（应走趋势策略）、阴跌不止的无底行情
- **市场阶段**：下跌市或震荡市中效果显著；牛市中机会较少

## 与上下游策略的关系

| 策略 | 关系 |
|------|------|
| `momentum_12_1` | 互补：动量找"涨的还在涨"，反转找"跌的要反弹" |
| `bottom_volume` | 互补：见底后的不同确认方式 |
| `emotion_cycle` | 配合：情绪恐慌底往往对应最佳超跌反弹时机 |
| `bull_trend` | 互斥：多头排列时不应使用本策略（见趋势过滤第 3 条） |

## 在管道中的角色

- **specialist 模式**：当市场状态为 `trending_down` 或 `sideways` 时优先选入
- **反转信号**：与趋势策略形成风险梯度——反转策略风险更高，仓位应更小
- **强制止损**：本策略要求硬止损和时间止损双重保护

```yaml
# 短期反转策略 / Short-term Reversal
name: short_term_reversal
display_name: 短期反转
description: 利用 A 股 5-10 日短期反转效应，在个股超跌后配合趋势/量能
  过滤找反弹机会。
category: reversal
core_rules: [2, 4, 6]
required_tools:
  - get_daily_history
  - analyze_trend
  - get_realtime_quote
default_priority: 14
market_regimes: [trending_down, sideways]
aliases: [短期反转, 超跌反弹, 反转, reversal]

instructions: |
  **短期反转策略（Short-term Reversal）**

  出处：Jegadeesh 1990；A 股 王永宏&赵学军 2001、鲁臻&邹恒甫 2007 -
  中国实证显著（夏普 1.5+，2005-2022 全周期）。

  适用场景：
  - 处于下行或震荡市，市场情绪偏空。
  - 个股在过去 5-10 日大幅下跌（> 8%），但当日出现企稳信号。
  - 与 12-1 动量策略互补：动量找延续，反转找反弹。
  - 与 bottom_volume 的差异：bottom_volume 强调"放量见底"（量能主导），
    本策略强调"5-10 日超跌 + 趋势过滤"（跌幅+趋势主导）。

  分析框架：

  1. **超跌判定（基础条件，全部满足才进入下一步）**
     - 过去 5 日累计跌幅 > 8%。
     - 过去 10 日累计跌幅 > 12%。
     - 当前价格距离 20 日均线 > 5% 偏离（越偏离反弹概率越大）。
     - 排除 ST、退市风险股、停牌股。

  2. **企稳信号（至少满足 2 条）**
     - 当日 K 线收阳（收盘 > 开盘）。
     - 当日成交量较 5 日均量放大 1.2 倍以上（恐慌盘+承接盘）。
     - 出现长下影线（下影线 / K 线实体 > 1.5）。
     - 当日未创新低（相对前 10 日最低点有 > 2% 缓冲）。

  3. **趋势过滤（必须执行，避免抄底下跌中继）**
     - 使用 `analyze_trend` 检查 MA20 斜率：
       - MA20 斜率走平或向上 → 反弹概率高（`sentiment_score +12`）。
       - MA20 斜率仍向下 → 反弹概率低（`sentiment_score -5`），需明确写"二次探底风险"。
     - 不能在 MA5 > MA10 > MA20 多头排列时使用（此时应走 `bull_trend`）。

  4. **入场偏好**
     - 首选：超跌 + 放量长下影 + MA20 走平。
     - 次选：超跌 + 连续两日缩量企稳（地量见底）。
     - 严拒：超跌 + 跌破前低 + 缩量阴跌。

  5. **止损规则（必须给出）**
     - 硬止损：买入价下方 5%，或前 10 日最低点下方 1%。
     - 时间止损：3 个交易日内未出现反弹 > 3%，需主动减仓。
     - 反弹目标：5 日均线（保守）/ MA20（乐观）。

  6. **输出规范**
     - 必须在 `buy_reason` 注明 "反转条件：{5日跌幅}{%} / {企稳信号数}条 / MA20斜率{方向}"。
     - 必须明确给出止损位（不能模糊）。
     - 避免在 `risk_warning` 写成"已经超跌所以安全"——超跌可能更超跌。
```
